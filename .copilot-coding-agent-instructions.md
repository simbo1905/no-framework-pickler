# Copilot Coding Agent Instructions for this Repository

## Java DOP Coding Standards (Summary)

- **TDD Required:** All code must include targeted unit tests. Never disable tests for logic yet to be written (Red-Green-Refactor).
- **Records & Sealed Interfaces:** Use records for data, sealed interfaces for protocols. Prefer static methods with records as parameters.
- **Scope:** Default to package-private. Use public only for cross-package APIs. Limit private to security code.
- **Package Structure:** Organize by feature, not layer. Fewer, cohesive, wide packages.
- **Documentation:** Use JEP 467 Markdown documentation comments (///), never legacy JavaDoc (/** ... */).
- **Data-Oriented Programming:** Separate immutable data (records) from behavior (static methods). Use pure functions, immutable collections, and defensive copies.
- **Functional Style:** Use Stream API, avoid imperative loops, prefer final variables, and exhaustive switch expressions over if-else.
- **Constants:** Never use magic numbers; always use enum constants. Use exhaustive switch over enums/sealed types.
- **Logging:** Use java.util.logging.Logger with appropriate levels. Use lambda logging for performance. Share package-private loggers when possible.
- **Compile/Test/Debug:** Use provided scripts for compile/test. Use logging levels to filter output, not grep. Focus tests with -Dtest= and logging levels.
- **Singletons:** Use sealed interfaces for singleton patterns, not legacy static classes.
- **Assertions:** Use Objects.requireNonNull for public APIs, assert for internal validation, and log assertion failures.

## Copilot Coding Agent Best Practices

- **Follow the above Java DOP Coding Standards.**
- **Always write targeted unit tests for new/changed code.**
- **Never comment out or disable tests for incomplete logic.**
- **Use JEP 467 Markdown documentation comments (///) for all public/protected/package-private APIs.**
- **Prefer package-private scope unless cross-package access is required.**
- **Never use magic numbers; use enums/constants.**
- **Use exhaustive switch expressions for enums/sealed types.**
- **Use Stream API and functional style.**
- **Use java.util.logging.Logger for all logging.**
- **Validate all public API inputs with Objects.requireNonNull.**
- **Use assert for internal invariants.**
